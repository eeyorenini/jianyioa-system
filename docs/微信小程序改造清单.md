## 一点五、已修复（2026-10-17 02:25）

### ✅ 修复 1 · tabBar 超过 5 项（阻塞启动）

**报错**：`Error: app.json: ["tabBar"]["list"] 不能超过 5 项` —— 微信开发者工具直接启动失败。

**原因**：原 tabBar 有 6 项（首页、项目、巡检、**派工**、采购、我的），而微信小程序硬上限是 5 项。uni-app/H5 端无此限制，所以本地 H5 一直正常，问题只在小程序端暴露。

**处理**：按决策**移除「派工」tab**（改动最小 —— 派工页 0 处 `switchTab` 依赖）。派工仍可从首页快捷入口「派工管理」进入。

改动文件：

| 文件 | 改动 |
|---|---|
| `src/pages.json` | tabBar 从 6 项减到 5 项，移除 `pages/dispatch/list` |
| `src/utils/permission.ts` | `TAB_BAR_PERMS` 同步为 5 项，索引重排（采购 4→3、我的 5→4） |

现有 tabBar：`首页 / 项目 / 巡检 / 采购 / 我的`

### ✅ 修复 2 · tabBar 图标是 SVG（小程序不渲染）

小程序 tabBar **不支持 SVG**，只认 PNG/JPG。

**更深的问题**：`src/static/` 里虽然有一批 `.png`，但**全是占位符**（同一个实心圆点，`tab-home.png` 与 `tab-project.png` 内容完全相同），且**缺少 `tab-purchase.png` / `tab-purchase-active.png`**。

**处理**：从 SVG 重新栅格化生成全部 10 个 PNG。

- 工具：自写的纯 Python 渲染器（解析 `path`/`polyline`/`circle`/`line`，含 SVG 圆弧转折线），用 Pillow 8 倍超采样描边后缩放
- 规格：**81×81**，透明背景，颜色取自 SVG（未选中 `#8E9BBA` / 选中 `#1E3A5F`）
- 脚本：`/tmp/gen_tabs.py`（临时；如需重做可复用）
- 同步位置：`src/static/`（构建源）和 `static/`（dev 模式），并删除已下线的 `tab-dispatch*.png`

### ⚠️ 踩坑记录：uni 构建不会清理旧产物

`rm -rf dist/build/mp-weixin` 被执行环境的 safe-delete 拦截后，构建**不会重写内容相同的静态文件**，导致 `tab-project.png` 仍是旧占位图（175B），而其他文件已更新。**每次重新生成图标后，必须确认产物里的文件大小与源一致**，必要时先彻底删除 `dist/build/mp-weixin` 再构建。

## 二、阻塞项清单（按优先级）

### 🔴 P0-1 · 请求地址全是相对路径（223 处）

小程序 `uni.request` **不接受相对路径**，必须绝对 HTTPS URL。

现状：全项目写成 `uni.request({ url: '/api/xxx' })`，构建产物里 `/api/` 出现 **223 次**，绝对域名 **0 次**。

**改法**：新增统一请求封装，集中注入 baseUrl。

```ts
// src/utils/request.ts（新建）
// #ifdef MP-WEIXIN
const BASE = 'https://erp.fujinwanjia.com'
// #endif
// #ifndef MP-WEIXIN
const BASE = ''
// #endif

export function req(options) {
  return uni.request({ ...options, url: BASE + options.url })
}
```

然后把各页面的 `uni.request` 换成 `req`。也可以利用 `App.vue` 里已有的 `uni.request` 包装（`App.vue:9-20` 目前只注入了 `x-user-id` / `x-user-role`），在那里顺手补 URL 前缀 —— **改动点集中，推荐走这条路**。

> 涉及文件：`stores/user.ts`、`utils/projectPicker.ts`、`utils/upload.ts`、`pages/**/*.vue`（约 20+ 个页面）

---

### 🔴 P0-2 · AppID 是占位的 `touristappid`

`src/manifest.json` 里 `mp-weixin.appid` 和顶层 `appid` **都是空串**，构建出的 `project.config.json` 落到默认值 `"appid": "touristappid"`（游客身份，无法上传代码、无法调用微信登录）。

**需要你提供**：微信公众平台申请的小程序 AppID（`wx` 开头 18 位）。拿到后填入：

```json
// src/manifest.json
"mp-weixin": { "appid": "wx________________" }
```

---

### 🔴 P0-3 · 后端没有小程序登录接口

小程序登录链路是 `wx.login()` → `code` → 后端调微信 `code2session` 换 `openid` / `session_key` → 换成本项目登录态。**当前后端没有这个接口。**

相关现状：
- 表已建好：`wechat_config`、`wechat_identities`、`wechat_users`、`wechat_templates`
- 但 `server.js:5048-5054` 的 `getWechatAccessToken()` 是 **TODO**，实际调用被注释掉
- `server.js:5006` 注释明写：「微信小程序订阅消息（stub — 待小程序上线后接入 SDK）」

**需要新增**：`POST /api/mp/login`（收 code，调 `https://api.weixin.qq.com/sns/jscode2session`，匹配 `employees` 手机号或 `wechat_identities` 落登录态）。

**需要你提供**：小程序 **AppSecret**（只放服务器 `system_settings` 的 `wechat_mp` 分类或 `wechat_config` 表，不要进 git）。

### 🟠 P1-5 · 浏览器专属 API 未隔离（6 处）

以下位置直接调用 `window.` / `document.`，小程序端会报错，需补 `#ifdef` 条件编译或改用 uni API：

| 文件:行 | 代码 | 建议 |
|---|---|---|
| `App.vue:28` | `window.addEventListener('unhandledrejection')` | 包 `#ifdef H5` |
| `pages/projects/detail.vue:1803-1804` | `document.addEventListener('visibilitychange')` | 包 `#ifdef H5` |
| `pages/inspection/detail.vue:150-151` | `window.location.hash` / `.search` 取路由参数 | 改 `onLoad(options)` |
| `pages/mine/my-logs.vue:215-220` | `document.getElementById/createElement/body.appendChild` | 包 `#ifdef H5` |
| `pages/purchase/detail.vue:259-263` | `window.location.hash` / `.search` 取路由参数 | 改 `onLoad(options)` |

> `utils/permission.ts:211-212` 已有 `typeof window !== 'undefined'` 保护，**无需改**。
> `voice-input.vue`、`contracts/contract-upload.vue`、`contracts/approval.vue`、`files/*.vue`、`material/inbound.vue` 已用 `#ifdef H5` 包好，**无需改**。

**取路由参数是重点**：H5 端靠解析 `window.location.hash` 拿参数，小程序端必须改用 `onLoad(options)`。涉及 `inspection/detail`、`purchase/detail`、`contracts/approval` 三处。

### 🟠 P1-6 · 文件上传 / 下载方式不同

H5 端用 `document.createElement('input')` 选文件、`window.open()` 打开文件（见 `contracts/contract-upload.vue`、`files/*.vue`、`projects/detail.vue`）。

小程序端要改成：
- 选文件 → `uni.chooseMessageFile()` / `uni.chooseMedia()`
- 上传 → `uni.uploadFile()`
- 下载预览 → `uni.downloadFile()` + `uni.openDocument()`

**额外坑**：小程序无法给 `<image>` / `uni.previewImage` 带自定义请求头，鉴权只能靠 URL query 拼 `user_id`（项目里 `utils/permission.ts` 的 `projectFileUrl()` 已是这个思路，可复用）。

---

### 🟡 P2-7 · tabBar 权限隐藏在小程序端失效

`utils/permission.ts` 的 `applyRoleTabBar()` 用 `uni.setTabBarItem({ index, visible })` 按角色隐藏 tab。**`visible` 参数是 uni-app 私有扩展，微信小程序不支持**，会静默失败。

**影响**：小程序端所有角色都会看到全部 6 个 tab（巡检、派工、采购不会按权限隐藏）。

**改法**：小程序端改用**自定义 tabBar**（`app.json` 配 `"custom": true` + 自绘 `custom-tab-bar/` 组件），或接受"tab 全显示、进去后按权限拦截"的降级方案。

---

### 🟡 P2-8 · 合法域名与备案

小程序要求：
1. `erp.fujinwanjia.com` 必须 **ICP 备案**
2. 在小程序后台「开发 → 开发设置 → 服务器域名」把 `https://erp.fujinwanjia.com` 加入 **request 合法域名**、**uploadFile 合法域名**、**downloadFile 合法域名**
3. 域名证书必须有效（当前 Let's Encrypt 已配，**注意 90 天自动续期**）

> `manifest.json` 里的 `urlCheck: false` 只是**微信开发者工具的本地开关**，真机调试和提交审核都不认，必须真配域名。

## 五、部署方式说明（和 H5 完全不同）

**小程序不走服务器部署**。流程是：

```
本地 npm run build:mp-weixin
  → 微信开发者工具导入 dist/build/mp-weixin
  → 点「上传」提交到微信后台
  → 在 mp.weixin.qq.com 提交审核
  → 审核通过后发布
```

后端 API 仍然是服务器上的 `https://erp.fujinwanjia.com`（3001 端口，宝塔 Node 项目 `jianyioa` 托管），**这部分已就绪**。

> 本次已上传的 `server/public-mobile-h5/`（移动端 H5 构建）与小程序无关，可保留或删除。
